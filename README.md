# CICAN CCTV — Public Legal Education

**Ireland first · European Union framework · Non-commercial**

This repository contains an independent educational website explaining the exceptional legal and data-protection issues raised when a private-sector organisation considers CCTV in toilet/restroom facilities.

## Important legal position
The Irish Data Protection Commission states that organisations should avoid CCTV where a reasonably high expectation of privacy exists (for example, over cubicles); the threshold for restroom CCTV more generally remains very high. Any controller must assess its own facts, necessity, proportionality, lawful basis and safeguards. The DPC's Article 36 process is prior consultation in specified high-residual-risk circumstances, not a general CCTV licence.
